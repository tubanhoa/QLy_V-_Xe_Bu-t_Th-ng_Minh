# Quy tắc Commit Message

- Mọi commit message từ nay về sau BẮT BUỘC phải viết bằng **Tiếng Việt**.
- Tuân thủ định dạng Conventional Commits:
  - `feat(<phạm-vi>): <mô tả thay đổi tính năng bằng tiếng Việt>`
  - `fix(<phạm-vi>): <mô tả sửa lỗi bằng tiếng Việt>`
  - `refactor(<phạm-vi>): <mô tả cấu trúc lại mã nguồn>`
  - `chore(<phạm-vi>): <cấu hình, cập nhật dependencies>`
  - `docs(<phạm-vi>): <tài liệu hướng dẫn>`
